# Career Compass

Career Compass is an AI-powered career assistant designed to help job seekers improve every stage of their job search.

The project aims to provide intelligent tools for:

- Resume analysis
- ATS optimization
- Job description analysis
- Skill gap identification
- AI-powered resume tailoring
- Cover letter generation
- Interview preparation
- Application tracking

> 🚧 This project is currently under active development.

## Tech Stack

- Python
- FastAPI
- React
- PostgreSQL
- Ollama
- Docker

## Project Status

The project is currently in the initial development phase.
